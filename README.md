# 🎈 BalloonClock 3D — 風船デジタル時計

3D空間に浮かぶ7セグ風デジタル時計と、赤いプッシュボタンの作品です。
ボタンを **ポチッ** と押すと、風船の空気が抜けて空気中を不規則に暴れ回ります。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要 / Three.js は CDN から読み込み）。

- **赤いボタンをクリック** → 風船が「プシュー！」と空気を噴き出しながらカオスに飛び回る
- もう一度ボタンを押す → 風船を再び膨らませてリセット
- **ドラッグ** で視点回転 / **ホイール** でズーム

## 仕組み

- 時計は Canvas に 7 セグメントを描いてテクスチャ化（コロンは点滅、日付つき）
- 風船は「噴射ノズルの向きがランダムウォーク → その逆向きに推力」という
  実際のしぼむ風船に近いカオス物理で暴れ回る
- 残り空気量に応じて縮小し、空になると床へぺしゃんこに落下
- ノズルからは空気パーティクルが噴き出す

## 技術

- [Three.js](https://threejs.org/) r160（ESM + importmap, CDN）
- 単一ファイル `index.html` のみ、依存インストール不要
