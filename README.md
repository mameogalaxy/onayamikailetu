# 🎈 BalloonClock 3D — 風船デジタル時計

3D空間に浮かぶ、**デジタル時計そのものが風船**になった変わり種の時計アプリ。
赤いボタンを押すと時計＝風船の空気が抜けて、ループ＆右往左往しながら暴れ回ります。
背景は**今いる場所の今日の天気**を反映。**アラーム＆サウンド**付きで、iPhoneの
ホーム画面に追加すればアプリのように使えます。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要 / Three.js は CDN）。

- **赤いボタンをタップ** → 「プシューッ」と音を立てて風船が暴れ回る🎈💨
- もう一度タップ → ふくらみ直して定位置に戻る
- **ドラッグ**で視点回転 / **ピンチ**でズーム

## 機能

- **風船＝デジタル時計**：時計本体がしぼんで3D空間を滑らかにループ・宙返り。割れると…
- **🐱 たま登場**：空気を出し切って風船が割れると、中から猫の「たま」が飛び出す（「にゃー」付き）
- **天気の背景切替**：`🌤 天気きりかえ`で 快晴/くもり/雨/雪/雷/夜… を手動で切替。
  空のグラデ・太陽/月・星・雲・雨・雪・稲光が変化（位置情報は不要）
- **アラーム**：時刻をセットして有効化。時間になると音が鳴り、風船も暴れる（設定はローカル保存）
- **操作**：1本指ドラッグで回転 / ピンチでズーム / **ダブルタップで視点リセット**
- **サウンド**：Web Audioで生成（音源ファイル不要・オフライン可）。空気抜けの「プシュー」音／アラーム音
- **PWA**：ホーム画面に追加でフルスクリーン起動。Service Workerで初回オンライン後はオフラインでも起動

## iPhone でホーム画面に追加する

1. Safari で `https://mameogalaxy.github.io/onayamikailetu/` を開く
2. 共有ボタン（□に↑）→ **「ホーム画面に追加」**
3. 追加されたアイコンから起動（フルスクリーンのアプリとして動きます）

> アラームは**アプリを開いている間**だけ鳴ります。iOSの仕様上、画面ロック中や
> バックグラウンドでは鳴りません（純正アラームのような常駐はWebアプリではできないためのWeb制約）。

## 技術メモ

- [Three.js](https://threejs.org/) r136（UMD, CDN）+ OrbitControls
- 7セグ時計・空・アイコンはすべて Canvas 描画（アイコンPNGは Node の zlib で生成）
- 単一ファイル `index.html` ＋ `manifest.webmanifest` / `sw.js` / `icon-*.png`
